# Nick's AI Camp — downloads

Installers for the Nick's AI Camp Mac app, for camp families. Install steps: https://nicksaicamp.com.au/download

## Third-party software

The Mac app bundles FFmpeg 9.0.1 (GNU GPL, built by martin-riedl.de with the configuration listed in `FFmpeg-build-and-license.txt` on each release). The corresponding FFmpeg source code is attached to every release as `ffmpeg-9.0.1.tar.xz`. It also bundles Node.js (MIT) and Chromium headless shell (BSD); their licence files are inside the app under `Contents/Resources/runtime/licenses`.
